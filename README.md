# 👔 CyberInterviewer (AI 赛博面试官)

一个基于大语言模型（LLM）的全栈异步 AI 面试智能体（Agent）系统。具备多轮对话状态流转、高并发异步架构、结构化多维评估以及数据大屏展示功能。

## 🌟 项目背景
在传统的 AI 面试应用中，大模型往往存在“老好人综合征”（评分虚高）和“无尽追问”（缺乏状态管理）的问题。本项目旨在打造一个具有工程完整性与算法严谨性的 AI 面试官，实现了从前端用户交互到后端状态机调度、再到数据持久化与可视化的完整 SaaS 闭环。

### 🏗️ 核心架构
- **交互层 (Bot)**: 基于 `discord.py` 和 `aiohttp` 的高并发异步服务员。
- **逻辑层 (API)**: 基于 `FastAPI` 构建后端大脑，内置状态机（State Machine）控制面试轮次（基础概念 -> 深度追问 -> 业务场景 -> 结束评估）。
- **算法层 (LLM)**: 接入 DeepSeek-Chat，支持上下文长记忆与动态 Prompt 模板调度。
- **存储层 (DB)**: 使用 `SQLite` 持久化封存用户的最终结构化评估报告。
- **展示层 (Web)**: 使用 `Streamlit` 和 `Pandas` 实时拉取数据库，构建现代化的面试记录大屏。

## 🔬 算法优化：结构化评分对比实验 (Eval)

本项目不仅仅是简单的 API 调用，还针对大模型的“打分区分度与稳定性”进行了量化评测与调优。

### 1️⃣ 为什么要做结构化评分？
Baseline 模型在打分时极易受候选人自信语气的干扰，导致“分数膨胀”。我们引入了 **V2 结构化多维评分系统**（知识深度 40 + 逻辑严密性 30 + 表达清晰度 30），强制 LLM 拆解评估维度。

### 2️⃣ 实验设计
- **测试集构建**: 构建 9 条涵盖高、中、低三个质量梯度的虚拟候选人回答（如关于 QuickSort 的追问）。
- **评测策略**: 使用 Python 并发脚本 (`advanced_eval.py`) 对每个样本进行 3 次重复采样，共计执行 54 次调用，以消除 LLM 单次生成的随机性。
- **观测指标**: 平均分（Mean）评估区分度，标准差（SD）评估打分稳定性。

### 3️⃣ 核心发现与结论
**💡 实验结果表明：** 相比于 Baseline 综合打分，结构化多维评分 Prompt (V2) 有效压制了错误回答的高分虚警，拉开了高低质量样本的梯度。同时，**整体评分稳定性波动下降了 27.0%**，极大提升了 AI 评估的可靠性与区分度。
